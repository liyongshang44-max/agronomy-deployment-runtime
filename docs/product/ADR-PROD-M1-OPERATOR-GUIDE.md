# ADR-PROD M1 — 农艺师浏览器操作说明

日期：2026-11-17
状态：M1 候选验收，待 CTO 集中裁决；M2 未完成
数据性质：仅隔离合成测试世界，不是实际田块或客户科学意见

## 管理员启动演示

在已获取仓库、已安装 Node.js 24 的计算机中运行：

    npm --prefix apps/adr-product run demo

在同一台计算机的浏览器打开 http://127.0.0.1:3080/ 。

演示服务默认仅监听 127.0.0.1。不要开放公网访问。农艺师只需要上述网页地址，不需要配置终端、API、Token 或授权引用。

## 农艺师独立操作步骤

1. 打开「总览」，确认 DEMO 标识与“合成测试世界、非农业行动许可”提示。
2. 进入「农艺知识」，查看来自 ADR Host 的知识和来源引用、原始主张、来源定位、限制。不能预览原文时，必须显示不可用。
3. 可选择登记一项候选来源的名称、所有者、版本、作物、地区、季节、所记录的权利依据。确认提交状态为 SUBMITTED，科学资格仍为 UNAVAILABLE，且没有 PDF 文件上传或保留。
4. 进入「适用性评估」，选择 QUALIFIED_SYNTHETIC_V03。其他未资格化场景不得选择。
5. 核对目标田块、季节、观测值、原始单位、空间与时间支持、ContextManifest；核对科学主张、来源内容哈希、合格知识 AuthorityRef 及使用限制。
6. 勾选两项确认后点击「运行 ADR 适用性评估」。确认获得新的 ApplicabilityAssessment AuthorityRef、Workbench Projection Hash、实际 ADR 分类、缺失上下文、冲突和限制。
7. 点击「开始人工复核计时」，选择复核结论并写备注，再点击「保存复核反馈」。确认反馈注明非权威，不会更改评估的科学裁决。
8. 下载「含证据的 HTML 报告」，检查报告包含精确评估引用、来源和观测证据、分类及复核结果。可用浏览器打印为 PDF。
9. 刷新页面，核查原操作 ID、原评估哈希和人工反馈仍可恢复；已记录的复核开始时间不得改变。
10. 进入「专家复核」查看真实 Host 的受授权队列及证据。注意该队列不包含全部历史案件。

## 应当出现的异常行为

- 请求超时、HTTP 5xx、响应解析失败或连接断开时，保留原始 operationId；不得将读取失败解释为可以生成新写入身份。
- 只有已确认终态并且明确点击「开始新案件」后才允许生成不同的操作 ID。
- 不能确认写入时应显示 UNKNOWN_OUTCOME 等待核对，不显示成功。
- 未记录独立复核开始事件时，人工复核耗时显示 UNKNOWN；不得使用评估创建时刻代替。
- 来源登记不签发 QualifiedKnowledge、RightsDecision、权限或 PDF 保留资格。
- 切换到正式 PILOT 模式却缺少 WP 身份和授权时必须 fail-closed，而不能回退 DEMO。

## 范围说明

M1 仅证明现有 ADR v0.3 合格合成科学世界通过实际 Pilot Host HTTP 能被浏览器完成适用性评估、查看证据、记录非权威反馈并导出报告。不证明真实客户部署、多租户生产隔离、知识自助资格发布、正式来源全文读取或商业验证。

WP 仍独立负责正式客户身份、权限、Pilot Host 资格和科学来源授权。PR #231 保持 Draft，不因 M1 测试直接合并主线。
